# Week 2 – Toolchain Mastery and ORFS Execution

## Objective

The objective of Week 2 is to develop independent RTL-to-GDS execution capability using OpenROAD Flow Scripts (ORFS). This includes running the complete flow in GitHub Codespaces, understanding the development toolchain, installing ORFS and OpenROAD locally, executing the flow on a local machine, and developing Unix debugging skills.

## Assignment Phases

### Phase 1 – ORFS Execution in GitHub Codespaces
- Repository setup
- Devcontainer build
- Tool version verification
- RTL-to-GDS execution
- Timing analysis
- Runtime measurement

### Phase 2 – Toolchain Understanding
- Dockerfile analysis
- install-openroad.sh analysis
- Toolchain mapping
- Flow architecture explanation

### Phase 3 – Local Installation
- ORFS installation
- Dependency installation
- Environment setup
- Official OpenROAD installation

### Phase 4 – Local RTL-to-GDS Execution
- Re-run Sky130 testcase
- Timing analysis
- Runtime comparison

### Phase 5 – Unix Debugging
- Unix commands
- Environment variables
- Log analysis
- Debugging techniques

## Repository Structure

This folder is organized according to the assignment phases. Each phase contains its own documentation, screenshots, and observations.
